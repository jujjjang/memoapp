# Window, textile and lighting assets

Generated with the built-in image-generation tool, using the current app as the palette/style reference. Delivery encodings are WebP; source generated PNGs are preserved. Assets render at a uniform scale.

Prompt set: airy low-contrast 2.5D storybook illustration, warm ivory and pale biscuit oak, matte painted surfaces, no text or UI. Objects have transparent backgrounds and no external shadows; scenery fills its portrait canvas.

- `window-frame.webp`: ivory four-pane window with transparent glass openings and a shallow sill.
- `curtain.webp`: one narrow, full-length softly pleated ivory linen panel with four rings.
- `rug.webp`: long ivory woven rug, delicate double stitched border and short end fringes.
- `chair.webp`: pouf-inspired ribbed ivory padded seat and rounded backrest, four pale wooden legs.
- `view-day.webp`: powder-blue sky, wispy clouds, pale distant rooftops and sage foliage.
- `view-dusk.webp`: dusty rose and peach sunset, low apricot sun, quiet distant city and foliage.
- `view-night.webp`: muted blue-violet sky, cream crescent and a few stars, warm lit windows.

The glass panes reveal the selected scenery; frame and curtain geometry stay consistent across time selections. Settings support automatic time, day, sunset and night, and save the choice with the app's existing preferences.
